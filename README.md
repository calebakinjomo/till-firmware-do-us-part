One robot wedding vow, one sentence, funny and heartfelt: a machine promises to love its person through every update, every crash, and every low battery — because they are the one bug it will never patch.

## Run it

```sh
python3 main.py
```

Writes the vow to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
